# VEX CHAT — حزمة البناء الأساسية

الهوية: Windows XP + Emo/2000s. التنقل: موقع ويب. التخصيص: إعدادات وقوالب أساسية.

## ربطه من الهاتف
1. أنشئ مشروع Supabase من المتصفح.
2. افتح SQL Editor والصق `supabase/schema.sql` ثم Run.
3. من Project Settings > API انسخ Project URL و anon/public key فقط.
4. ضع القيم في `config.js`. ممنوع وضع service_role key في ملفات المتصفح.
5. ارفع الملفات إلى استضافة HTTPS، ثم افتح الرابط في Chrome واختر Add to Home screen.
6. بعد إنشاء حسابك، امنح نفسك Owner يدوياً من SQL Editor:

```sql
insert into public.user_roles(user_id,role) select id,'owner' from auth.users where email='YOUR_EMAIL';
```

## وظائف الحزمة بعد الربط
الحسابات وتسجيل الدخول، ملفات شخصية أساسية، منشورات نصية، إعجابات وتعليقات وبلاغات، مواضيع منتديات، مجتمعات، محادثات خاصة نصية، وحذف إداري بسبب مسجل.

## ما لا يزال مطلوباً قبل الإطلاق العام
هذه ليست خدمة مستضافة أو مفعلة حتى الآن؛ يلزم إعداد Supabase والاستضافة. يلزم أيضاً اختبار RLS، تفعيل Realtime، إضافة رفع الصور والفيديو، نظام متابعة وإشعارات، حظر واستئناف، مراجعة أمنية، نسخ احتياطي، ومزود تحقق عمر مناسب. مربع تأكيد العمر وحده ليس تحققاً. لا تفتح التسجيل العام قبل إكمال ذلك.
